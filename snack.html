計算規則及資料欄位
  • Dermes、Reenex、Elyze、Evvus、Vigene 的 On Sales Floor 同事：$90；Staff List 的 M 欄 Organization Level 2 Code 為 OS 的全體同事：$80。
  • 一般 OA 先按正常資格判斷。只有未能符合試用期條件的 OA，才額外檢查 Staff List 的 AB 欄 Job Staff Category Code 為 CON、R 欄 Job Position Description 為 Office Assistant，且 Latest Hire Date 早於所選零食錢月份 1 號；符合則視為有資格。
  • cic sheet 內的同事會按該 sheet 的 Brand 及 Floor for Foodpanda 分組；只有 Entitle 為 Y 才無條件 $90，不受試用期、Resign Last Day 及請假日限制。
  • 其他同事必須在 Job movement 有「Probation Confirmed」記錄；若沒有該記錄，但 Staff List 的 Latest Hire Date 在所選零食錢月份最後一天前已超過一年，亦視為已過試用期。
  • Resign Record 的 Last Employment Date 在零食錢月份最後一天或之前，該月不會有零食錢；例如 9 月提出離職、10 月才是最後工作日，仍會有 9 月零食錢。J 欄有 WITHDRAW 的離職記錄不計算。
  • 請假日以 Leave 的 Start Date 屬於所選月份、Cancelled 不為 Yes、狀態為 Pending 或 Approved 的 Duration 合計；Regular Day Off 不計入。
  • ACC 以 Tableu 的 Center 對應 Acc 的 Organization Level 3 Code。未能對應會顯示「未對應」。
  • 個別資料缺失會列為未符合資格，方便跟進。
